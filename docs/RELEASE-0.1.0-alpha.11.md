# 0.1.0-alpha.11：DeepSeek 官端导入

此前 DS 官端 ZIP 被误当成 Lite 完整备份，可能在识别格式前显示「备份文件过大」。本版新增独立导入入口，并自动识别误选到 Lite 恢复入口的 DS 包。

- 支持新版分会话 ZIP、旧版 conversations.json ZIP、外层目录和兼容的新版格式标记。按需读取大文件，解析与解压在 Worker 运行。
- 对齐 Orbis 已有的空/缺失标题、null model、长消息、空中断消息、新增/变化的历史片段兼容。重复键、坏分支关系、坏 CRC 等仍拒绝，不静默丢记录。
- 预览并选择会话/分支，默认尊重原包当前分支；文字、思考与时间保留，重复导入跳过，变化或不同分支追加窗口。单会话保存失败不覆盖现有聊天，已完成会话可继续保留。
- 图片/音频可选恢复，默认保留附件引用。历史搜索和工具内容不执行，不恢复账号或连接密钥，不上传原包。
- 长聊天每页显示 80 条，支持前后翻页及回到最新；不改变原始聊天、模型历史或缓存布局。

验证：61 项逻辑测试、类型检查、生产构建；合成浏览器导入、分支、重复导入、翻页与重开回归。另在隔离的本机 Chromium 用约 828 MiB 官端原包核验 9 会话、选中分支 22,754 条消息，与独立原包解析的正文/思考/角色/时间摘要逐会话一致；重复新增为 0。原包和私人内容不在仓库或附件中。手机 Safari 实机尚未验收。

下载静态包后按 [自行部署](../SELF-HOSTING.md) 操作；原在线入口保持不变。更新请刷新或关闭重开，勿清除网站数据。

限制：媒体单文件 16 MiB、每会话 64 MiB；其他附件保留引用。单会话 JSON/旧版逐会话缓冲仍有浏览器保护范围，ZIP64/分卷/加密 ZIP 暂不支持。详见 [FAQ](FAQ.zh-CN.md)。原 ZIP 请保留。Lite 完整备份与 Android 全量备份仍不是同一格式，原有 lint 问题未在本次全面处理。

# 0.1.0-alpha.16

DeepSeek 官端导出包的兼容性改进，与 Orbis 本次导入改进同步。

- 原时间缺失或无效时保留消息顺序，显示“原时间未知”，不把导入时间当成原发言时间。窗口排序使用会话时间或导入时间。
- v3 包缺少索引时，仅从同一个、经过校验的导出目录恢复会话列表，预览会提示核对数量。已有索引损坏、会话身份冲突或多个导出目录仍会拒绝，不静默忽略。
- 附件缺少可选大小字段时可恢复；已声明但不一致的大小及 ZIP 校验错误仍会拒绝。
- 保留导出时置顶状态、思考耗时，历史检索用默认折叠的只读卡片展示，可打开原来源。历史记录不重新执行，也不生成工具调用。
- 可选恢复 ZIP 内 PDF、TXT、Markdown、CSV、DOCX、XLSX 文档并下载；单文件 16 MiB、每会话附件合计 64 MiB。完整备份可保存恢复这些文档。未支持类型与缺失附件继续保留引用，不自动下载远程内容。

保持原有旧版包、长消息、未知片段、分支选择和逐会话保存行为。请保管原 ZIP；导入或打开记录不会调用模型。之后发消息仍按当前上下文设置发送所选历史，文档下载不代表模型具有读取该文件类型的能力。

验证使用合成导出包和本地浏览器；不将其等同于每一种私人导出包或所有移动浏览器均已验收。

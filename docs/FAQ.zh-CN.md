# Orbis Web Lite 常见问题

适用于 **0.1.0-alpha.10**。[首页](../README.md) · [自行部署](../SELF-HOSTING.md)

## 手机能直接用吗？要 VPS、安卓手机或 ChatGPT 账号吗？

直接用 Safari / Chrome 打开 [现有入口](https://consult.azhi-xinxin.cn/orbis-web/)，填写自己的模型配置即可。普通用户不需要买 VPS、运行安卓设备、Wi-Fi 调试、ChatGPT 或 Orbis 社区账号。模型账号/API Key 由你自己准备，模型、搜索和语音按所选服务计费。

这是可添加主屏幕的网页应用，不是 iOS 原生安装包。没有承诺所有浏览器、机型和模型接口都有同样能力。

## 电脑要一直开着吗？只有手机能不能自行部署？

使用公共入口不需要你的电脑开机；网站和模型服务需要在线。若用自己的电脑托管，首次加载和更新时那台电脑要在线。缓存的页面可以离线查看已有资料，生成、搜索、ASR/TTS 仍要联网。

自己搭建只需合适的 HTTPS 静态托管，不一定要 VPS。Release 提供现成静态包，可以上传到托管平台；“只用手机完整构建并长期把手机当服务器”的流程没有专项验收。直接在文件管理器打开 HTML 不是完整部署，语音、模块和 Service Worker 需要正确站点环境。

## 网页跑在哪里？访客多了会拖累服务器吗？

网站发送公开的页面、字体、WASM 与记忆模型；界面、本地数据库和语义计算在访客浏览器运行；模型/语音/MCP 请求由浏览器发往用户配置的服务。

本站没有集中保存聊天的数据库，也不执行每次模型推理。但首次加载、更新、并发下载仍消耗带宽与流量，浏览器缓存只能减少重复下载，不能承诺零成本或固定可承载人数。

## 别人访问网址，会进入我的 VPS 或拿走密钥吗？

访问公开网页不等于取得 SSH、管理接口或私网权限。每位访客填自己的密钥，默认在其标签页 sessionStorage 保存；选中「在此设备保存密钥」后才写入其浏览器 localStorage。

仍需信任所用站点：浏览器执行站点提供的代码，维护者必须保护服务器和发布账号，公开目录不能放 `.env`、管理凭据或私人备份。模型等服务会收到相关请求；“静态站点”不代表绝对无风险。

## 聊天会同步吗？微信有记录，Safari 为什么没有？

当前没有云账号和跨设备自动同步。聊天、记忆、附件、配置在当前浏览器 IndexedDB。Chrome、Safari、微信内置网页、主屏幕 Web App 可能彼此独立，另一台手机也不会自动出现同样资料。

固定一个入口。迁移前在旧入口导出 Lite 完整 ZIP 或加密包，再在新入口导入；追加并去重，同 ID 有差异的窗口另存。导入不会建立后续持续同步。

## 清理缓存会把聊天清掉吗？

先看清理项目，不能一概说“不会”：

| 操作 | 影响 |
| --- | --- |
| 仅缓存图片与文件、临时文件 | 通常移除页面/离线资源，聊天通常保留；再次打开需下载资源 |
| Cookie 与网站数据、网站存储、所有网站数据 | 会清除本地聊天、记忆、附件、配置和已保存密钥 |
| 清除浏览器应用数据、卸载浏览器 | 可能移除全部本地资料 |
| 删除主屏幕 Web App | 数据是否同时删除因系统而异，先备份 |
| 关闭普通网页 | 通常保留聊天，未持久保存的密钥随会话结束消失 |
| 关闭无痕窗口 | 通常删除无痕环境的数据 |

“一键清理”“清除历史记录与网站数据”可能组合多项。持久存储许可只降低自动回收风险，不能阻止主动删除，也不替代备份。Safari 可能因存储压力等原因回收网站数据，见 [WebKit 存储策略](https://webkit.org/blog/14403/updates-to-storage-policy/)。

## 网页更新会丢记录吗？换网址呢？

相同站点与入口更新静态文件时，本地数据库不会仅因换了 JS 文件而主动清空。保存当前操作后刷新或关闭重开，核对设置中的版本；不要用“清除网站数据”来刷新版本。

换域名、浏览器或入口不能当作同地更新，先备份再迁移。不要依赖主屏幕自动复制或同步，运营者也应保持稳定入口。

## 备份选哪种？能完整搬到 Android Orbis 吗？

| 格式 | 用途 |
| --- | --- |
| Lite 完整 ZIP | 原路恢复 Lite：窗口、记忆版本、压缩原文与回退点、注入记录、媒体、设置、哨兵与 MCP；不含密钥 |
| 加密 Lite `.orbis` | 同类资料，可选择包含模型/语音/MCP 密钥；设备内密码加密，密码丢失无法找回 |
| `orbis_chat` v1 JSON | Android 通用文字入口所需的文字、思考、时间与引用投影；不是 Android 全量备份 |

Lite ZIP 当前不能直接恢复为 Android 3.0.0 全部数据，原生端导入全过程未专项验收。图片、音频、完整记忆请留在 Lite 完整包里，不要只存文字 JSON 后就删除 Lite。

完整包不包含未发送草稿。普通 ZIP 上限128 MiB、解压内容上限250 MiB，加密包还有编码空间限制，超限会报错。导出后确认文件已存入“文件/下载”。导入设置可选、密钥另行勾选；哨兵导入暂停、新 MCP 工具关闭，避免两端重复执行。

## 三档记忆有什么区别？“独立”是隔离窗口吗？

| 档位 | 查询范围 | 自动注入 |
| --- | --- | --- |
| 轻量 | 当前窗口 | 不自动注入，仍可工具存查 |
| 标准 | 同一浏览器内跨窗口 | 常驻最多7条/350估算 tokens，动态命中预算900，摘要最多3条、短原文最多1条 |
| 独立 | 同一跨窗口库 | 总预算2000，摘要最多5条、短原文最多3条，常驻仍受原约束 |

“独立”沿用档位名称，不表示此处隔离窗口。Lite 的轻量档本窗口隔离与 Android 原版语义有差异。预算只限制自动带入，原文完整保存，AI 可分页查询。本地语义当前优先索引最新64个有效摘要片段，不是无限资料全部即时检索。

## 时间、世界书、哨兵会影响缓存吗？

每条消息时间/时区在发送或开始记录时固定保存；当前时钟不每轮写进固定系统提示，也不重新计算旧消息。`orbis_time` 按需查最新设备时间，不是服务端校时。

本轮记忆选择冻结，工具续轮复用；动态资料靠近当前消息，减少早期内容变动。修改提示词、世界书、工具清单或压缩历史仍可能改变前缀。Lite 世界书是一整段窗口背景，没有 Android 的关键词条目扫描开关。

哨兵触发会新增宿主事件，以默认折叠时间点展示；展开仅改变显示，不改写消息或额外请求模型。实际缓存取决于接口与服务商，不能保证99%或100%。「用量记录」区分未知和明确0，工具续轮分别记数；上下文圆环是文字估算，不是图片等实际计费。

## 关页、锁屏后还能主动联系吗？

当前不保证。人类只开关哨兵总授权，AI 再自主创建/暂停/删除具体规则；开启不会自动新建规则，关闭保留规则但不触发。只在网页运行时检查，后台、锁屏和系统挂起可能延后或停止。

没有服务端代跑、Web Push、手机通知读取、屏幕/定位监控或系统电话。晚到超过5分钟的事件跳过，已领取事件不自动重试；“已触发”不等于模型已经成功回复。添加主屏幕不会绕过后台限制。

## AI 能发语音或来电吗？为什么没有声音？

「允许 AI 发语音条」「允许 AI 来电」分别授权，默认关闭。语音条需 DeepSeek TTS，保存真实音频；系统朗读只能读文字，不生成可保存的语音文件。语音与聊天服务地址相同时才能复用聊天密钥，不同服务分别填写。

来电只在当前打开窗口显示邀请，接听后启用麦克风；拒绝/超时/停止不录音，15分钟内不重复邀请，刷新不重拨。通话为录音→ASR→模型→TTS→继续听的前台逐句流程，可停顿发送、打断、挂断，不是全双工，也不拨手机号。

被浏览器拦截播放时点「开启声音并播放」，重用已有音频，不重复 TTS；同时检查音量、静音、语音配置和权限。锁屏或系统中断可能暂停录音/播放。

挂断总结会额外调用一次当前模型，原文/音频留在完整记录中；失败可手动重试，刷新不自动重复总结。字幕可滚动并查看完整内容。

## MCP 必须接吗？能控制电脑或读手机其他应用吗？

不必接，内置记忆、压缩、时间和聊天不依赖 MCP。当前只支持允许跨域的远程 Streamable HTTP，工具默认关闭、逐项开启。没有 stdio、本地进程、旧 SSE 或 OAuth 配置。

浏览器不会凭空拥有电脑执行或其他手机应用权限。外部能力取决于连接服务的授权；停止或撤回聊天不倒转已完成外部动作，结果未知不自动重放。Safari 连不上 MCP 可跳过，不影响内置功能。

## 支持哪些模型？智能搜索为什么在别的接口没有？

支持 Messages 与 OpenAI 兼容 Chat Completions；不代表所有兼容中转的私有参数、视觉、工具、语音和缓存已适配。基础地址、模型名按服务商填写，服务端需允许网页 CORS。浏览器跨域错误通常不能靠换密钥解决。

内置智能搜索限定 DeepSeek 官方地址的 `deepseek-flash`，可与深度思考同开，服务端执行并返回真实来源；其他模型/网关不会自动获得该能力。见 [DeepSeek Web Tools](https://api-docs.deepseek.com/guides/web_tools/)。相关服务可能另外计费。

## 人类思考链是隐藏草稿吗？AI 能替我打开吗？

不是隐藏草稿，开启后填写的内容会与本轮正文一起发给模型。开关归人类，AI 没有控制工具。关闭保留未发送草稿，但不附带新消息；已发送内容仍在历史里。「深度思考」是模型参数，与人类填写的思考区分开。

欢迎称呼默认只显示在界面，主动开启「AI 可见」后才从下轮带入。

# 0.1.0-alpha.12：聊天分支与手动压缩

修复超长导入会话达到模型上限后，无法再通过聊天请求 AI 压缩的操作死路。

- 右上圆环可从当前进度开启分支；每条消息更多菜单可从该完整轮开启分支。原窗口与设置保留，不重放工具、不复制哨兵计划。分支本身不减少上下文。
- 人类可生成分段摘要或自行填写，再核对并应用。分段使用当前模型连接，只带累计摘要和下一段资料；每段最多 48,000 字符、输出上限 4,096 token，字符不等于 token。页面显示预计请求次数，按服务商计费，不自动重试。
- 摘要不包含图片/音频内容和模型思考过程；仅保留媒体文件名。若仍超限可缩小分段，或直接填写摘要；提示词、世界书和保留消息过大仍需调整。
- 手动压缩始终保留完整原文窗口，最近一次可回退并保留后续消息。取消、请求失败、截断摘要或原聊天变化不会应用压缩。
- 标准/独立档的分支继续共享记忆；轻量档复制当前窗口自己的记忆后隔离。原压缩事件和撤销点留在原窗口，不转移到新分支。

验证：69 项逻辑测试与类型检查通过。浏览器已验证超限 400 后分段压缩续聊、失败/取消不落库、确认前原文不变、分支独立、刷新与回退、四种宽度；原 AI 工具压缩续轮也通过。测试使用合成历史与模拟模型接口，真实用户手机及真实付费模型质量需使用反馈；不承诺摘要无损或所有服务的上下文容量。

# 0.1.0-alpha.14：压缩后长消息发送与时间前缀修复

压缩产生可检索记忆后，旧版从四个字符起会先等待本地语义模型加载/计算，三个字符及以下跳过；等待期间人类消息尚未保存，30秒超时又销毁模型，慢设备可能反复冷加载。本版先保存并显示人类消息，语义检索最多等待1.5秒，超时继续使用关键词记忆及工具查询并发送；本地模型加载保留给下一轮，初始化超过60秒仍会释放。此上限只针对本地检索，不是模型服务回复速度保证。

- 检索停止、工作线程启动失败、运行异常都能退出等待；迟到结果不会注入已冻结请求。停止后消息保留，但不会自动重发或执行工具。
- 保留既有语义召回能力和记忆预算，没有关闭用户记忆开关；关键词注入、记忆查询、分支和压缩回退保持。
- 模型请求不再在历史AI正文前添加宿主时间JSON，保留人类/哨兵时间资料和orbis_time工具，并明确时间资料不是回复模板。
- 旧回复开头完整匹配宿主格式的重复时间前缀，在显示、复制/朗读和后续请求投影中清理；原始聊天和导出不重写。流式输出也适用，普通日期、正文中引用、代码块和不匹配的JSON保留。签名思考和工具协议块原样保留。

验证：79项逻辑测试通过；浏览器控制本地模型不就绪，验证三字/四字/长句发送、消息先保存、停止不发请求、工作线程失败降级、刷新不重放、原摘要/记忆不变和时间前缀处理。真实捆绑BGE/ONNX在桌面浏览器成功加载并召回，不调用外部向量服务。另验证两种部署路径、AI工具压缩、时间及哨兵、人工分段压缩与分支回归。模型接口为合成响应，没有代用私人聊天或调用收费模型；手机上这次修复与真实模型回复仍待使用反馈。

关闭旧页面后重新打开原网址即可更新，请保留网站数据。旧版未保存下来的中间摘要无法凭空恢复；本版沿用alpha.13逐段保存和断点续接。
